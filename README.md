# 🧮 CodeAlpha Calculator

A modern, responsive, multi-module computational engine built using HTML, CSS, and JavaScript.

## Features
* 📁 **Collapsible Drawer Mode** — Standard & Scientific viewports combined via an absolute mobile-style sliding layout switch.
* 🎙️ **Real-Time Voice Input** — Hands-free formula processing powered by the built-in Web Speech AI pipeline.
* 💱 **Live Exchange Engine** — Converts calculation results across global currencies instantly via live API connection.
* 🔲 **Matrix Algebra Suite** — Standalone workspace for computing 2x2 determinants, transpositions, and inverses.
* 📏 **Dimensional Unit Hub** — Instant mathematical conversions for Temperature, Data Size, and Speed metrics.
* 📈 **Math Curve Canvas Plotter** — Interactive HTML5 graph rendering system to chart functional math curves visually.
* 📊 **Calculation History Tape** — Sidebar ledger stream tracking past operations with a single-click recall.
* 📱 **Responsive Micro-Chassis** — Layout parameter optimizations preventing text-truncation on compact screens.
* 🎨 **Bespoke Theme Switcher** — Smooth interface color transformations between Dark and Light variables.

## Technologies Used
* HTML5
* CSS3 (Variables, Custom Grids, & Glassmorphism Aesthetics)
* Vanilla JavaScript (ES6+ Object-Oriented State Engine)
